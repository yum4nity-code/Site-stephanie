# IDEAS_INBOX — boîte à idées partagée

Ce fichier est le **point d’entrée simple pour déposer de nouvelles idées** concernant le site de Stéphanie.

Il est volontairement placé à la racine du dépôt pour être facile à trouver, à lire et à modifier depuis GitHub ou par un assistant IA connecté au dépôt.

## Mode d’emploi

Quand Stéphanie donne une idée à son IA, l’IA peut l’ajouter ici **sans avoir besoin de décider immédiatement si elle sera retenue**.

Règles :

1. **Ajouter, ne pas écraser** les idées déjà présentes.
2. Une idée = un bloc court, daté, avec son auteur si connu.
3. Ne pas modifier les prix, offres, textes validés ou décisions du projet depuis ce fichier.
4. Une idée déposée ici est **une proposition**, pas une décision.
5. Quand une idée est validée, la déplacer ou la recopier dans `docs/IDEAS.md` et, si elle devient une décision, mettre aussi à jour `HANDOFF.md` et les fichiers concernés.
6. Ne jamais supprimer une idée rejetée sans laisser une trace : la marquer `REJETÉE` avec une courte raison.

## Format à utiliser

```md
### [AAAA-MM-JJ] Titre court de l’idée
**Auteur :** Stéphanie / Gwen / IA / autre
**Statut :** À étudier

Idée :
Description en quelques lignes.

Pourquoi :
Le problème ou l’objectif visé.

Notes éventuelles :
Contraintes, exemples, références, questions ouvertes.
```

Statuts possibles :

- `À étudier`
- `À préciser`
- `Validée`
- `Implémentée`
- `Rejetée`
